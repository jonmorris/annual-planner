# Pending decision-log entries

Each file here is one decision waiting to be folded into
[`../DECISION-LOG.md`](../DECISION-LOG.md). Name it `YYYY-MM-DD-short-name.md`
and put exactly one table row in it. See "How to keep this file" in
DECISION-LOG.md for the rules.

Print the pending rows, in fold order, from the repo root:

    cat docs/decision-log/2*.md
